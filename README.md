# دليل وصفات القهوة

دليل شخصي لوصفات الإسبريسو، مبني على تجاربي مع معداتي.

**رابط الأداة:** https://talaquf.github.io/coffee-recipes/

## المزايا

- **بطاقة لكل محصول ومشروب** تعرض الوصفة المعتمدة: درجة الطحن على Monolith و HG-1، والحرارة، والجرعة والناتج والنسبة والوقت.
- **التجارب السابقة** على نفس المحصول تنطوي تحت البطاقة للمقارنة.
- **«تجربة عليها»** تنسخ إعدادات الوصفة للنموذج، فتغيّر متغير واحد وتسجّل.
- **بحث وتصفية** حسب المحصول أو البلد أو المحمصة، وحسب فلات وايت أو كابتشينو.
- **الإعدادات:** اختيار مكينة الإسبريسو وإضافة المطاحن المتوفرة أو إزالتها، فيتغيّر النموذج وبطاقات الوصفات تلقائيًا.
- **العربية والإنجليزية** مع زر للتبديل بينهما.
- **التحقق من التحديثات** من داخل الصفحة.
- **تصدير واستيراد** نسخة احتياطية بصيغة JSON، تشمل الإعدادات.

## التشغيل على GitHub Pages

1. أنشئ مستودعاً عاماً باسم `coffee-recipes`.
2. ارفع `index.html` في جذر المستودع.
3. من **Settings → Pages**: المصدر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`، ثم **Save**.
4. افتح الرابط بعد دقيقة أو دقيقتين، ومن قائمة المتصفح اختر **إضافة إلى الشاشة الرئيسية**.

> البيانات تُحفظ في متصفحك فقط (`localStorage`) ولا تُرفع إلى GitHub أو أي مكان آخر.
